# gost-docx

Работает с .docx по правилам из `references/gost-rules.md` (единый источник параметров со ссылками на пункты ГОСТ) и `references/niaspo-structure.md` (структура КР НиАСПО). Содержание текста не пишет и не меняет.

## Выбор режима

Сразу в начале спросить, что нужно. Три варианта:

1. Аудит существующего файла: только чтение, отчёт в .md.
2. Форматирование копии по ГОСТ: исходный файл не трогается, результат `Имя_gost.docx`.
3. Создание нового .docx с нуля: сначала спрашиваются данные (см. ниже).

Если пользователь уже назвал режим, переспрашивать не нужно.

## Режим 1. Аудит

Запуск:

    python3 ~/.claude/skills/gost-docx/scripts/audit_docx.py файл.docx --out отчёт.md

Скрипт не меняет файл. Коды возврата: 0 — нарушений нет, 1 — есть ошибки (предупреждения не влияют), 2 — файл не открыт. Проверяются: формат A4, поля 30/15/20/20 мм, нижний колонтитул с PAGE по центру, отступ 1,25 см, интервал 1,5, нулевые интервалы до и после, выравнивание по ширине, Times New Roman 14 пт, точка в конце заголовка, формат подписей «Рисунок N – Название», порядок ссылок в квадратных скобках, местоимения первого лица, символ «•».

Не проверяются: номера страниц в содержании, поля в таблицах, нумерация разделов, формулы. Их нужно смотреть глазами после рендера.

## Режим 2. Форматирование копии

Исходный файл не перезаписывается. Работа идёт над копией `_gost.docx`. Перед запуском спросить, какие пункты из списка конфликтов применять (см. ниже). Затем проверить результат режимом 1 и провалидировать `scripts/office/validate.py` из базового скилла `docx`.

Запуск:

    python3 ~/.claude/skills/gost-docx/scripts/apply_gost.py файл.docx

Результат: `файл_gost.docx` рядом с исходным. Исходный файл не меняется. Скрипт выравнивает поля и размер страницы, добавляет колонтитул с PAGE по центру, задаёт стиль Normal и оформляет абзацы основного текста. Заголовки, подписи, таблицы и титул не трогает, поэтому после прогона нужно смотреть аудитом: ошибки по содержанию (порядок ссылок, местоимения, маркеры) остаются.

## Режим 3. Создание

Сначала спросить данные, без них документ не собирается:

- тема (подставляется в «Настройка и администрирование «…»»);
- ФИО студента и группа;
- ФИО и должность руководителя;
- срок представления;
- главы и подразделы (если не заданы, предложить по структуре из `niaspo-structure.md`);
- список источников (если не задан, оставить пустой шаблон, не выдумывать).

Текст глав, выводов и источников в этом режиме не придумывать. Запуск:

    NODE_PATH=~/.claude/skills/gost-docx/scripts/node_modules node ~/.claude/skills/gost-docx/scripts/build_gost.js задание.json файл.docx

Формат `задание.json`: `introduction`, `chapters` (массив объектов `{heading, paragraphs}`), `conclusion`, `sources`. Все значения пишет пользователь. Структурные элементы (введение, заключение, список источников) начинаются с новой страницы. Создание через npm `docx` версии 9.15.3, установленной локально в `scripts/`.

## Конфликты: спрашивать, не решать молча

Если методичка и ГОСТ расходятся, спросить пользователя. Шаблон вопроса:

    Конфликт: [что именно]. Методичка: [вариант А]. ГОСТ 7.32 (пункт N): [вариант Б].
    Какой применить?

Открытые вопросы из `gost-rules.md`: аннотация или реферат; заголовки разделов; титульный лист; ссылки по ГОСТ 7.1 или ГОСТ Р 7.0.100; Courier New и кнопки; листинги как рисунки; лимит 50 страниц.

Уже решено пользователем: реферат по ГОСТ 7.32 и ГОСТ 7.9; заголовки разделов по ГОСТ 7.32, 6.2.3; титульный лист по методичке; библиография по ГОСТ Р 7.0.100-2018.

## Окружение

- Python 3 с lxml. Для рендера и проверки внешнего вида: LibreOffice (`soffice`, путь `/opt/homebrew/bin/soffice`), PDF переводится в картинки через PyMuPDF (`fitz`). `pdftoppm` в системе нет.
- Node: `scripts/` содержит локальный `docx@9.15.3`. Глобальной установки не требуется.
- Базовый скилл `/Users/leo/.agents/skills/docx` не изменяется. Его `scripts/office/validate.py` вызывается по пути.
- Системный Python блокирует `pip install` (PEP 668). Для валидатора нужен venv с `defusedxml` и `lxml`, например `python3 -m venv ~/.gost-venv && ~/.gost-venv/bin/pip install defusedxml==0.7.1 lxml`.
