# Правила оформления: единый источник

Источники: ГОСТ 7.32-2017 (далее «ГОСТ 7.32»), ГОСТ Р 7.0.100-2018 (далее «ГОСТ Р 7.0.100»), методичка РТУ МИРЭА (далее «методичка»). Номера пунктов даны по тексту ГОСТ 7.32.

Решения проекта:
- Для нового документа титульная страница создаётся как заглушка «ТИТУЛЬНЫЙ ЛИСТ» без личных данных. Существующий титульный лист сохраняется.
- Заголовки разделов: ГОСТ 7.32, 6.2.3 (абзацный отступ, порядковый номер, полужирный, первая заглавная, без точки).
- Библиографические описания: ГОСТ Р 7.0.100-2018. Этот стандарт не заменяет правила отсылок в тексте.
- Если методичка и ГОСТ расходятся, решение принимается один раз в начале работы и фиксируется для выбранного профиля.

## Перечисления

Маркер — тире, отбивается пробелом; либо «а)», «б)» (кроме е, з, й, о, ч, ъ, ы, ь) при ссылках; либо арабские с закрывающей скобкой. Точку «•» не использовать (методичка; ГОСТ 7.32, 6.4.6). Перечисления с абзацного отступа в столбик.

## Формулы

Отдельная строка по центру; выше и ниже не менее одной пустой строки; номер в круглых скобках справа: (1); приложения: (А.1). Пояснения после формулы, с новой строки, первая строка начинается со слова «где» без двоеточия (ГОСТ 7.32, 6.8.1–6.8.5). Выбор OMML или текста с табуляцией — открытое решение в плане.

## Сноски и примечания

Примечание: слово «Примечание» с абзацного отступа; одно примечание без номера, несколько — с номерами (ГОСТ 7.32, 6.7.2–6.7.3). Сноска: надстрочный номер, отделена короткой тонкой линией слева (6.7.4).

## Ссылки и список источников

- Отсылка в тексте: номер в квадратных скобках. ГОСТ 7.32, 6.9.1 допускает сквозную нумерацию по всему отчёту или отдельную нумерацию по разделам; выбрать вариант по профилю или решению пользователя.
- Список: номер с точкой, с абзацного отступа, в порядке появления ссылок (ГОСТ 7.32, 6.16).
- Библиографическое описание: ГОСТ Р 7.0.100-2018. Для сетевых ресурсов указывать URL и дату обращения; при необходимости — режим доступа и вид содержания. Не выдумывать автора или формулировку «коллектив авторов».
- Объём списка: 5–20 наименований (методичка).

## Приложения

Каждое с новой страницы; обозначение «ПРИЛОЖЕНИЕ А» — по центру в верхней части, заголовок — отдельной строкой по центру, полужирный, с первой прописной, без точки (ГОСТ 7.32, 6.17.3–6.17.4). Одно приложение — «ПРИЛОЖЕНИЕ А». Нумерация формул и таблиц внутри — с буквой приложения. Все приложения перечислены в содержании (6.17.7).

## Содержание

Заголовок по центру. Записи — отдельные абзацы, выровнены влево. Номер страницы по правому краю, отточие (leader dots) между заголовком и номером (ГОСТ 7.32, 5.4.1, 6.13). Уровни: разделы с начала, подразделы с отступом 2 знака (0,5 см), пункты с отступом 4 знака (1 см) (методичка; ГОСТ 7.32, 5.4.1). Рекомендуется автоматическое содержание Word по стилям заголовков (открытое решение, дефолт — авто).

## Термины и перечень сокращений

Термины — слева без абзацного отступа в алфавитном порядке, определение справа через тире, без точки в конце строки (ГОСТ 7.32, 6.14). Сокращения — то же, кириллица затем латиница (6.15; методичка). Вводная фраза: «В настоящем отчете о НИР применяют следующие термины…» / «…следующие сокращения и обозначения» (5.5.2, 5.6.1). Отдельный перечень нужен при более чем трёх условных обозначениях; при менее чем трёх пояснение дают при первом упоминании (5.6.2–5.6.3). Ровно три обозначения не считать автоматическим нарушением.

## Титульный лист

Шаблон методички (Приложение 1): ведомство, организация, институт, кафедра, «КУРСОВАЯ РАБОТА», дисциплина, профиль, направление, тема, студент, группа, руководитель, подписи, место и год. УДК, регистрационные номера и грифы ГОСТ 7.32 (6.10) для курсовой работы не используются (решение пользователя).
