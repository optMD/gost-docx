## Обязательные пункты задания (8 вопросов)

Каждый вопрос должен быть отражён в записке и презентации. Соответствие разделам:

| Пункт задания | Где в записке | Где в презентации |
|---|---|---|
| 1. Анализ предметной области контейнерной платформы на базе Docker | Глава 1 | слайды 3 |
| 2. Обоснование выбора технологий | Глава 2 | слайд 4 |
| 3. Пять и более контейнеров (минимум два для демонстрации; количество обосновать при защите) | Глава 2 (проектирование), Глава 3 (реализация) | слайды 5, 6 |
| 4. Кластерная архитектура (Docker Swarm, Kubernetes или иная) | Глава 2 (концепция), Глава 3 | слайды 5, 6 |
| 5. CI/CD (при невозможности практической демонстрации — теоретически) | Глава 2, Глава 3 | слайд 6 |
| 6. Деплой созданной инфраструктуры | Глава 3 (инструкция по настройке) | слайд 6, 7 |
| 7. Сетевое межконтейнерное взаимодействие (минимально работоспособная конфигурация) | Глава 3 | слайд 6, 7 |
| 8. Презентация к защите | — | вся презентация |

Задание: пункты 3–7 относятся к практике, их скриншоты и инструкции — в Главе 3.

## Содержание глав (методичка)

**Глава 1.** Теоретическая база: определения терминов, общепринятые подходы, описание объектов настройки, цель настройки, при необходимости математический аппарат. Конкурентные решения: кто применяет, откуда информация, фирма, автор. Таблица достоинств и недостатков. Требования к аппаратной части и системному ПО (для Docker-платформы).

**Глава 2.** Концепция: структура и функциональность, этапы и последовательность настройки. Обоснование инструментов — метод сравнения по показателям качества: строки — технологии, верхняя строка — признаки (показатели качества), ячейки — экспертные оценки (например, по пятибалльной шкале), выбирается максимум по всем признакам. Затем технологический комплекс: технологии, приложения, возможности каждого, задача в рамках КР.

**Глава 3.** Практика: скриншоты, описание действий, результат. Документирование: инструкция по настройке для конкретных условий. Упор — демонстрация настройки и развёртывания контейнеров, кластера, межконтейнерного взаимодействия. CI/CD — теоретически, если практика невозможна.

## Введение: задачи (примерный перечень из методички)

- Анализ предметной области
- Формирование требований к продукту
- Формирование концепции продукта/процесса
- Выбор инструментов разработки/исследования/настройки
- Разработка дизайна интерфейса (при необходимости)
- Разработка продукта/инструкции по настройке
- Документирование продукта/процесса настройки (выработка рекомендаций)

Объект исследования — объект предметной области, в рамках которого проектируется система. Предмет исследования — часть объекта, автоматизация или исследование которой является целью работы.

## Правила языка (задание, методичка)

- Только третье лицо. Не использовать «я», «мы», «мне», «нами», «наш» и т.п.
- Научный стиль (образцы — научные статьи из e-library).
- Сокращения: при первом появлении — полная расшифровка, далее в «Перечне сокращений и обозначений».
- Термины: раздел «Термины и определения», формулировка «В настоящем отчете о НИР применяют следующие термины с соответствующими определениями» (ГОСТ 7.32, 5.5.2). Для КР допустима адаптация формулировки.

## Библиография (ГОСТ Р 7.0.100-2018, решение пользователя)

- Порядок ссылок в тексте: [1], [2]…; первая ссылка — [1].
- Интернет-источник: название, автор (или «коллектив авторов»), полный путь до страницы (адреса ресурса недостаточно), дата обращения.
- Объём: 5–20 наименований.

## Презентация (лист задания + образец 4Па…pdf)

Не более 10 слайдов из расчёта 5 минут. Обязательные слайды по заданию:

1. Титульный: министерство, университет, институт, кафедра, тема, автор (ФИО, группа), руководитель (должность, ФИО), город, год.
2. Цель и задачи.
3. Анализ предметной области: аналоги и технологии аналогов.
4. Перечень используемых технологий.
5. Логика работы: структурная схема элементов.
6. Взаимодействие элементов, технологические процессы.
7. Демонстрация работы: скриншоты.
8. Результаты КР.

Слайды 9–10 — резерв (при необходимости).
