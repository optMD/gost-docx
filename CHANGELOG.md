# История изменений

Все заметные изменения проекта фиксируются в этом файле.

## Unreleased

### Добавлено

- проверка структуры JSON перед генерацией DOCX с указанием проблемного поля;
- команда `validate` для проверки задания JSON без создания DOCX;
- переносимая точка входа `scripts/gost_docx.py` для режимов `audit`, `format` и `build`;
- диагностика окружения через `gost_docx.py doctor`;
- вывод версии через `gost_docx.py --version`;
- проверки структуры skill-пакета и отсутствия машинно-зависимых путей;
- установка skill через Skills CLI для Codex, Claude Code и других агентов.

### Изменено

- команды skill больше не зависят от `~/.claude`, `~/.agents` или конкретного рабочего каталога;
- README и английская версия README синхронизированы и сокращены до сценариев быстрого старта;
- добавлены GitHub Actions-проверки переносимости пакета.

### Исправлено

- аудит и форматирование отклоняют путь результата, если он указывает на исходный DOCX, в том числе через жёсткую ссылку.

## v0.1.0 — черновик

### Добавлено

- режим аудита существующих документов `.docx` без изменения исходного файла;
- форматирование безопасной копии документа с суффиксом `_gost.docx`;
- генерация документов `.docx` из пользовательской JSON-спецификации;
- поддержка профилей документов и пользовательских методичек;
- базовые правила ГОСТ 7.32-2017 и ГОСТ Р 7.0.100-2018;
- нейтральная заглушка титульного листа без персональных данных;
- автоматическое содержание Word, главы, подразделы, список источников и приложения;
- проверка структуры документов и регрессионные тесты;
- CI-проверки проекта.

### Изменено

- механика документа отделена от его содержательного наполнения;
- профиль NiASPO удалён из базовой реализации, а требования к методичкам переведены в подключаемые профили;
- уточнены правила форматирования, аудита и генерации документов;
- основная документация переведена на русский язык и дополнена инструкциями для пользователей skill.
